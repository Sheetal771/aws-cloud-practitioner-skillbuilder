# AWS Cloud Practitioner Hands-On Project Showcase 🚀

Welcome! This repository serves as a centralized portfolio for the **12 hands-on cloud projects** I built and deployed via AWS Skill Builder / AWS SimuLearn. 

The goal of this showcase is to demonstrate practical, foundational cloud implementation across compute, storage, security, networking, and cost optimization.

AWS Services
Amazon Elastic Compute Cloud
Amazon EC2 Auto Scaling
Amazon Simple Storage Service
Amazon VPC
Amazon Relational Database Service

## 🛠️ Project Categorization

### 1. Cloud Computing Essentials
* The web team wants a solution to improve the reliability of their beach wave conditions page.

### 2. Cloud First Steps
* The island stabilization team wants to increase the reliability and availability of its current stabilization system.
* 
### 3. Computing Solutions
*  The school wants to upgrade its class scheduling system, currently running on an Amazon EC2 instance, to provide greater computing power and memory capacity.

### 4. First NoSQL Database
*   The streaming entertainment company wants to collect viewer behavior data in a high-performance, scalable database to enhance its streaming features.

### 5. Networking Concepts
*  The bank wants to establish a network architecture that securely controls communication between its internal resources and the internet.

### 6. Cloud Economics
*   The surf shop wants a cost estimate for scalable cloud architecture to support their online store.

### 7. File Systems in the Cloud
*   The pet modeling agency wants a way to share files across its branch offices without managing physical storage infrastructure.

### 8. Databases in Practice
*   The insurance company wants to help its database administrators spend less time in operational tasks, such as patching and managing database infrastructure.
  They also want a solution that improves database availability and efficiency.

### 9. Core Security Concepts
*   The stock exchange wants to restrict support engineers' system access to only those actions required for their specific roles, enhancing overall security controls.

### 10. Auto-Healing and Scaling Applications
*    The gaming café wants to implement auto-healing servers and restrict users to a specific provisioning capacity.

### 11. Highly Available Web Applications
*    The travel agency wants to make sure their web application remains available to customers even if some system components fail.

### 12. Connecting VPCs
*    The Marketing team wants to maintain separate network environments for each department while ensuring they can still communicate with one another.
  

## 📈 Key Takeaways & Cloud Core Skills
*   **Architecture Mapping:** Visualized deployment paths using architecture diagrams to mirror enterprise infrastructure.
*   **Cost & Security Conscious:** Built every lab with a "least-privilege" security model and evaluated cost-optimized tiering choices.
